### 🔍 Studi Kasus: LLM Output Evaluation & QA for Interactive Web Components

**Deskripsi Ringkas:**
Menganalisis dan menguji performa model AI generatif (*Large Language Models*) tingkat lanjut dalam menghasilkan komponen antarmuka web interaktif (HTML/Tailwind CSS) berdasarkan kriteria fungsionalitas, akurasi logika, dan kepatuhan instruksi.

**Tugas & Tanggung Jawab:**
- **Pengujian Fungsional:** Menguji widget kalkulator biaya interaktif yang dihasilkan AI untuk memastikan semua fitur UI (seperti kalkulasi *real-time* dan tombol ekspor/cetak) berjalan sesuai spesifikasi.
- **Identifikasi Cacat (*Defect Tagging*):** Menemukan dan mendokumentasikan ketidaksesuaian antara deskripsi teks AI dengan perilaku antarmuka aktual (seperti kegagalan status visual *checkbox* dan tombol cetak yang non-aktif).
- **Penilaian Multi-Dimensi:** Memberikan evaluasi terstruktur pada 7 dimensi utama (termasuk *Outcome Quality, Trust & Grounding,* dan *Collaboration Quality*) disertai analisis rasional dalam bahasa Inggris.
- **Penggunaan Alat AI Consistency:** Memanfaatkan alat kalibrasi evaluasi internal (Compass) untuk memastikan penilaian konsisten sebelum kualifikasi akhir.

- ### 🔍 Case Study: LLM Output Evaluation & QA for Interactive Web Components

**Brief Description:**
Analyzed and stress-tested the performance of advanced generative AI models (Large Language Models) in producing interactive web interface components (HTML/Tailwind CSS) based on functionality, logical accuracy, and instruction adherence.

**Tasks & Responsibilities:**
- **Functional Testing:** Evaluated AI-generated interactive cost calculator widgets to ensure all UI features (e.g., real-time calculations and export/print buttons) functioned according to specifications.
- **Defect Tagging:** Identified and documented discrepancies between AI text descriptions and actual interface behavior (e.g., failed visual states of checkboxes and inactive print buttons).
- **Multi-Dimensional Assessment:** Provided structured evaluations across 7 key dimensions (including Outcome Quality, Trust & Grounding, and Collaboration Quality) supported by comprehensive rationales in English.
- **AI Consistency Tool Utilization:** Leveraged internal evaluation calibration tools (Compass) to ensure scoring consistency prior to final qualification.
